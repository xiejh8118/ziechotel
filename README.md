## 上传到 GitHub
1. 解压本压缩包。
2. 打开 GitHub 仓库 `xiejh8118/ziechotel`。
3. 点击 `Add file` → `Upload files`。
4. 上传 `index.html`、`styles.css`、`script.js` 和整个 `assets` 文件夹。
5. GitHub 网页上传文件夹不方便时，可把 assets 内全部图片一起拖入上传区；必须保持图片位于 `assets` 目录。
6. 点击 `Commit changes`。
7. 等待 Vercel 自动部署。

## 注意
不要删除 `index.html`、`styles.css`、`script.js` 和 `assets` 文件夹。
